## 核心结论

- A 总耗时为 **786.446 秒（13 分 06.446 秒）**，B 总耗时为 **182.582 秒（3 分 02.582 秒）**。
- A 比 B 多耗时 **603.864 秒（10 分 03.864 秒）**，是 B 的 **4.307 倍**，即耗时增加 **330.74%**。
- 反过来看，B 相比 A 减少了 **76.78%** 的总耗时。
- 差距几乎全部来自 `VideoEditDenoisingStage`：A 的去噪耗时为 **714.110 秒**，B 为 **118.238 秒**；A 是 B 的 **6.040 倍**，多出 **595.871 秒**。这一项占两次运行总耗时差值的 **98.68%**。
- 除去去噪阶段，其他已记录阶段的耗时差异整体较小，因此优化或排查应优先聚焦去噪阶段的执行路径、硬件负载和运行配置。
