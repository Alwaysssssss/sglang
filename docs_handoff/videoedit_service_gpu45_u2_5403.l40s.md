### 2026-10-05 补充：前后处理及接口额外开销

本节仅重新分析 2026-10-04 已保存的正式请求，没有重新发起推理或变更服务。`inference_time_s` 包含服务内部的读写与处理，不等于纯 DiT 时间。

#### 统计口径

对每个正式请求定义：`S` 为响应中的 `inference_time_s`，`C` 为客户端 `client_seconds`，`D` 为 DiT 阶段时间，`M` 为不重叠的全部模型阶段时间之和。

- `M` 包括文本/CLIP 条件准备、VAE 条件编码、DiT、VAE 解码。双卡文本/CLIP 使用合并的 `VideoEditConditioningEncodingStage`，不重复加其子项；单卡使用文本和图像编码两个阶段。
- 服务内除 DiT 外时间为 `S-D`；扣除全部模型阶段后的服务内剩余开销为 `S-M`；接口额外开销为 `C-S`；全部模型阶段之外的端到端开销为 `C-M`。
- 先逐请求相减，再分别取正式样本中位数；各行中位数不保证相加成立，尤其 `median(C-S)` 不等于 `median(C)-median(S)`。预热和启动期间的诊断轮均不纳入统计。
- `S-M` 是差值估算，包含视频/mask/参考图读取、裁剪与窗口编排、贴回、音频处理、编码写出、调度和未细分等待，不能称为单独测得的纯 CPU 时间。现有记录不能把这些前后处理环节逐一拆开。
- 模型阶段采用服务外层 stage 计时，包含其权重搬运、通信和阶段内部处理，不是纯 GPU kernel 时间。接口差值包含网关、请求准入、状态轮询和响应观测误差，不是纯网络耗时。
