description: 根据高可信的一手来源调查问题，并将结论写入仓库中的 Markdown 文件。当用户希望研究某个主题、收集文档或 API 事实，或把资料阅读工作委派给后台智能体时使用。
---

启动一个**后台智能体**开展研究，这样它阅读资料时你可以继续工作。

它的任务：

1. 根据**一手来源**调查问题——官方文档、源代码、规格、第一方 API，而不是对它们的二手转述。为每项结论追溯到真正负责该事实的来源。
2. 将研究结论写入单个 Markdown 文件，并为每项结论标注来源。
3. 保存到仓库现有的同类笔记位置并遵循既有约定；若没有约定，则放到合理位置并说明路径。
