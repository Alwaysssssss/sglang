---
name: handoff
description: 将当前对话压缩成交接文档，供另一个智能体接手。
argument-hint: "下一次会话要用来做什么？"
disable-model-invocation: true
---

编写一份概括当前对话的交接文档，让新的智能体能够继续工作。将其保存到用户操作系统的临时目录，而不是当前工作区。

在文档中加入“建议技能”一节，推荐该智能体应调用的技能。

不要重复其他产物（规格、计划、ADR、议题、提交、差异）中已有的内容；改为通过路径或 URL 引用它们。

隐去所有敏感信息，例如 API 密钥、密码或个人身份信息。

如果用户传入了参数，将其视为下一次会话重点的描述，并据此调整文档。
