# GLOSSARY.md 格式

`GLOSSARY.md` 是教学工作区的规范语言。所有讲解、练习和学习记录都应遵循其中的术语。构建术语表本身也是学习的一部分：把概念压缩为紧凑定义，能够证明用户理解了它。

## 结构

```md
# {主题}术语表

{用一两句话说明术语表覆盖的主题。}

## 术语

**肌肥大**：
在反复训练中，由机械张力和代谢压力驱动的肌肉增长。
_避免使用_：增重、变壮

**渐进超负荷**：
随时间通过负荷、训练量或强度系统性增加对肌肉的要求。
_避免使用_：更用力、升级

**RPE（主观用力程度）**：
用 1–10 评价一组训练的主观难度，其中 10 表示力竭，8 表示还可完成两次重复。
_避免使用_：努力分数、强度评级
```

## 规则

- **只有用户理解后才加入术语。**术语表记录压缩后的知识，不是供用户初次学习的字典。用户刚接触概念时，等到能够正确使用后再加入。
- **做出明确选择。**同一概念存在多个词语时，选择最佳术语，并将其余列为应避免的别名。语言由此得到压缩。
- **保持定义紧凑。**用一两句话定义术语*是什么*，而不是它做什么或如何操作。
- **在定义中使用术语表已有词汇。**术语加入后，在所有地方优先使用，包括其他定义内部，使复杂术语以后更易理解。
- **自然形成聚类时用子标题分组，**例如 `## 解剖`、`## 编程`。术语紧密相关时可使用平铺列表。
- **明确标记歧义。**某个术语在更广领域中使用松散时，写明本工作区的约定，例如：“在本工作区中，‘组’始终指工作组；热身组单独记录。”
- **随着理解加深而修订。**用户第一周写下的定义到第六周可能已不正确，应就地更新，不保留过时条目。
