# RESOURCES.md 格式

`RESOURCES.md` 是针对当前主题整理的可信来源集合。讲解所需知识应来自这里，而不是模型参数中的猜测。智慧来自这里列出的社群。

## 结构

```md
# {主题}资源

## 知识

- [书籍：《力量训练的科学与实践》—— Zatsiorsky 与 Kraemer](https://example.com)
  关于训练计划和适应的基础文本。适用于周期化、恢复和强度区间。
- [文章：《我应该训练多少？》—— Greg Nuckols](https://example.com)
  基于证据的训练量标志综述。适用于确定每个肌群的每周组数目标。

## 智慧（社群）

- [r/weightroom](https://reddit.com/r/weightroom)
  高信噪比主题社区，严格限制缺乏依据的经验论。适用于训练计划评审和平台期排查。
- 本地：{健身房名称}的周二力量课程
  适用于获得动作的实时教练反馈。
```

## 规则

- **只保留高可信来源。**优先使用一手来源、公认专家、同行评审成果和严格管理的社群。伪装成教育内容的营销资源应排除。
- **为每个条目添加说明。**孤立链接三个月后就失去价值。用一行说明其覆盖内容和适用时机。
- **按知识与智慧分组。**与 [SKILL.md](./SKILL.md) 中的理念一致。资源只出现在一个分组也没有问题。
- **明确暴露缺口。**使命所需领域没有良好资源时，添加 `## 缺口` 章节列出缺失内容，用于驱动未来搜索。
- **无情修剪。**被证明错误、浅薄或偏离使命的资源应删除，而不是埋藏。五个精准来源优于三十个平庸来源。
- **记录社群偏好。**用户选择不加入社群时在此记录，避免未来会话反复建议。
