# 分诊标签

技能使用五种规范分诊角色。本文件将这些角色映射到当前仓库问题跟踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 当前跟踪器标签       | 含义                               |
| -------------------------- | -------------------- | ---------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此问题单             |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息             |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，可由无人值守智能体处理   |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现                       |
| `wontfix`                  | `wontfix`            | 不会处理                           |

技能提到某个角色时，例如“应用可供无人值守智能体处理的分诊标签”，使用此表中对应的标签字符串。

编辑右侧列，使其符合当前跟踪器实际使用的词汇。
