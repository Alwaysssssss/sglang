---
name: resolving-merge-conflicts
description: "需要解决正在进行的 Git 合并或变基冲突时使用。"
---

1. **查看当前状态**。检查合并或变基状态、Git 历史以及冲突文件。

2. **找到每项冲突的一手依据**。深入理解每项改动为何产生及其原始意图。阅读提交消息，查看 PR 以及原始议题或工单。

3. **解决每个冲突块。** 尽可能保留双方意图。若无法兼容，选择符合本次合并既定目标的一方，并说明取舍。**不要**发明新行为。始终完成解决，绝不使用 `--abort`。

4. 找出并运行项目的**自动化检查**——通常依次为类型检查、测试和格式化。修复合并造成的所有问题。

5. **完成合并或变基。** 暂存所有内容并提交。若在变基，则继续变基流程，直到所有提交都完成变基。
